Bienvenido a OpenClaw

OpenClaw es tu propio asistente de IA autohospedado. Convierte tu computadora en un servidor inteligente capaz de conectarse a Telegram, navegar por la web y ejecutar tareas complejas de forma autónoma.

Guía para Principiantes

No necesitas ser programador. Esta guía te llevará paso a paso desde "cero" hasta tener tu propio bot de IA funcionando en Telegram.

Conceptos Clave

Terminal

La ventana negra donde escribes órdenes. En Windows es "PowerShell" o "CMD", en Mac es "Terminal". Es el volante de tu computadora.

Gateway

El "cerebro" de OpenClaw. Es el programa que corre en segundo plano esperando tus mensajes.

JSON

Archivos de configuración. Son simples archivos de texto donde guardas tus claves secretas y preferencias.

Node.js

La tecnología base. Necesitas tenerlo instalado para que OpenClaw pueda funcionar.

1 Instalación

Antes de empezar en Windows (Requisitos Previos)

En una PC limpia con Windows 10 (2004+) o Windows 11, abre PowerShell como Administrador y ejecuta estos comandos en orden antes de instalar OpenClaw:

1. Permitir ejecución de scripts en PowerShell (si pregunta, escribe S o Y):
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
2. Instalar Git (necesario para descargar dependencias): Plan B: Descargador manual (.exe)
winget install --id Git.Git -e --source winget
3. Instalar Node.js (motor base de OpenClaw): Plan B: Instalador manual (.msi)
winget install OpenJS.NodeJS
4. WSL2 (Opcional pero recomendado para máxima estabilidad): Guía manual Microsoft
wsl --install

Importante: Cierra y vuelve a abrir PowerShell después de instalar Git y Node.js (o reinicia Windows si instalaste WSL2) para que el sistema reconozca los nuevos comandos.

Selecciona tu sistema operativo y copia el comando correspondiente en tu terminal. El instalador automático se encargará de todo.

Mac / Linux Bash
bash — 80x24 
curl -fsSL https://openclaw.ai/install.sh | bash
PowerShell
PowerShell 
iwr -useb https://openclaw.ai/install.ps1 | iex
CMD (Símbolo sistema)
cmd.exe 
curl -fsSL https://openclaw.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Verificación de Instalación

Cierra y vuelve a abrir la terminal, luego ejecuta este comando. Si ves el número de versión, OpenClaw quedó instalado (el servicio gateway se iniciará en el Paso 2).

openclaw --version

2 Configuración Inicial

Ejecuta el asistente de configuración con instalación automática del servicio en segundo plano (daemon) para conectar tu proveedor de IA y dejar el Gateway listo:

Terminal 
openclaw onboard --install-daemon

¿Cómo conseguir tu API Key? (Paso a paso con Google y otras opciones)

Opción Principal Recomendada (Gratis): Google Gemini (Google AI Studio)

  1. Ingresa a aistudio.google.com/apikey e inicia sesión con tu cuenta de Google (Gmail).
  2. Haz clic en el botón Create API key (si es tu primera vez, acepta los términos y elige Create API key in new project o selecciona un proyecto existente).
  3. Copia la clave generada (comienza con AIza...) y guárdala en un lugar seguro.
  4. En el asistente de OpenClaw, elige Google / Gemini como proveedor, pega esa API Key y selecciona el modelo recomendado (ej. gemini-2.5-flash o gemini-2.0-flash).

Alternativa Gratuita: OpenRouter + DeepSeek R1

Regístrate gratis en openrouter.ai/keys, haz clic en Create Key, selecciona OpenRouter en el asistente y usa el modelo deepseek/deepseek-r1.

Opciones de Pago: OpenAI / Anthropic

Si eliges OpenAI (sk-...) o Anthropic, requieren cargar saldo prepago en sus consolas API (platform.openai.com o console.anthropic.com). Una suscripción normal de ChatGPT Plus o Claude Pro no incluye la API Key.

Pasos rápidos dentro del Asistente

  • Selecciona QuickStart.
  • Elige Google (Gemini) como proveedor de IA (u otro como OpenRouter u OpenAI) y pega tu API Key.
  • Si el asistente te ofrece configurar Telegram en ese momento, también puedes hacerlo directo desde ahí.

Verificar que el Gateway quedó corriendo

Al terminar el asistente, comprueba que el servicio aparezca como running:

openclaw gateway status
openclaw gateway start

Si status muestra que está detenido, ejecuta openclaw gateway start para arrancarlo.

Panel de Control (Dashboard)

Para ver la interfaz gráfica en tu navegador:

openclaw dashboard

3 Conectar Telegram

Paso A: Crear el Bot con BotFather

  1. Abre Telegram y busca @BotFather (el oficial con tilde azul).
  2. Envía /newbot.
  3. Elige un nombre visible y luego un usuario que termine en bot (ej. MiOpenClaw_bot).
  4. Importante: Copia el API TOKEN (algo como 123456:ABC-DEF...) que te entrega al final.

Paso B: Configurar el Token en OpenClaw

Opción 1 (Recomendada y sin editar archivos a mano)

Si no configuraste Telegram durante el onboard, ejecuta el configurador interactivo y elige el canal Telegram para pegar tu token de forma guiada:

openclaw configure

Opción 2 (Manual): Editar el archivo openclaw.json

Abre el archivo directamente desde tu terminal con el comando según tu sistema:

Windows (PowerShell)
notepad $HOME\.openclaw\openclaw.json
Mac / Linux
nano ~/.openclaw/openclaw.json

Asegúrate de que el bloque "telegram" quede dentro de la sección "channels" (respeta las llaves y comas con las demás secciones) y guarda el archivo:

openclaw.json (dentro de channels) 
"channels": {
  "telegram": {
    "enabled": true,
    "botToken": "PEGA_AQUI_TU_TOKEN",
    "dmPolicy": "pairing"
  }
}

Paso C (Crítico): Reiniciar el Gateway para aplicar los cambios

Después de guardar tu configuración, el bot no responderá hasta que reinicies el servicio. Ejecuta:

1. Reiniciar servicio 
openclaw gateway restart
2. Confirmar que quedó activo 
openclaw gateway status

4 Seguridad (Pairing)

Por seguridad, tu bot ignorará a cualquiera (incluso a ti) hasta que lo autorices. Este proceso se llama "Pairing".

  1. 1

    Saluda a tu bot

    Busca tu nuevo bot en Telegram, presiona Iniciar (o envía un "Hola"). Él te responderá con un código de emparejamiento (ej. XY123AB).

  2. 2

    Autoriza en Terminal

    Ejecuta este comando reemplazando CODIGO_AQUI por tu código sin corchetes ni comillas (por ejemplo: openclaw pairing approve telegram XY123AB):

    openclaw pairing approve telegram CODIGO_AQUI
  3. 3

    ¡Prueba tu Asistente!

    Vuelve al chat con tu bot en Telegram y envíale una primera instrucción (ej. "Hola, ¿estás en línea? Dime qué puedes hacer"). Si responde, ¡todo quedó funcionando al 100%!

5 Herramientas

Browser (Navegador)

Permite a la IA navegar por internet, leer páginas web y extraer información en tiempo real.

Exec (Comandos)

Permite a la IA ejecutar comandos en tu computadora, mover archivos y correr scripts.

! Solución de Problemas

Error: "command not found"

Cierra y vuelve a abrir la terminal. A veces el sistema necesita reiniciarse para encontrar el nuevo programa instalado.

El bot no responde

Ejecuta openclaw doctor para que el sistema busque errores automáticamente.
