Cómo Encender o Apagar Smart App Control sin Formatear en Windows 11

Hasta la versión 25H2, si apagabas el Control Inteligente de Aplicaciones (Smart App Control), la única forma de volver a encenderlo era haciendo una instalación limpia de Windows. En la versión 26H2 ya se puede alternar dinámicamente mediante PowerShell y el Registro de Windows.

NOVEDAD EN WINDOWS 11 26H2

Windows 11 26H2 introduce dos grandes avances en seguridad a nivel de kernel: la posibilidad de conmutar Smart App Control sin reinstalar (el tutorial central de esta página) y, de forma paralela e independiente, la inclusión de Sysmon nativo para telemetría forense. Al final de la página encontrarás una sección dedicada a Sysmon para no mezclar ambos conceptos.

Comparativa: Windows 11 25H2 vs. 26H2

Característica Windows 11 25H2 y anteriores Windows 11 26H2 (Actual)
Smart App Control (SAC) Bloqueo irreversible si se apaga. Requiere formateo completo. Conmutable vía Registro (CI\Policy) con solo reiniciar el equipo.
Modo Evaluación Solo en primer arranque tras instalación limpia. Reactivable forzando el estado de política en modo 2.
Auditoría Sysmon (Telemetría de eventos · Módulo independiente de SAC) Requiere descargar e instalar suite Sysinternals externa. Integrado en el kernel como característica nativa opcional.

Valores de VerifiedAndReputablePolicyState

Valor 0 OFF / APAGADO

Smart App Control está completamente desactivado. No realiza comprobaciones en la nube ni bloquea ejecutables no firmados.

Valor 1 ON / ENFORCEMENT

Smart App Control activo. Bloquea de forma estricta aplicaciones maliciosas, no confiables o sin firma digital válida.

Valor 2 EVALUATION

Modo evaluación silenciosa. Aprende los patrones de uso del equipo para evaluar si puede activarse sin generar fricción.

PARTE 1

Control Inteligente de Aplicaciones (SAC)

Requisito fundamental

Todos los comandos deben ejecutarse en una ventana de PowerShell abierta como Administrador. Presiona Win + X y selecciona Terminal (Administrador) o Windows PowerShell (Administrador).

1

Consultar el estado actual de Smart App Control

Consulta el valor almacenado en la clave de directivas de Integridad de Código (CI\Policy):

PowerShell (Admin) · Consulta de Estado
Get-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy" -Name "VerifiedAndReputablePolicyState"
Salida esperada: 
VerifiedAndReputablePolicyState : 0    (O bien 1 si está activo, 2 en evaluación)
2

Activar Smart App Control directamente sin reinstalar Windows

Establece el valor en 1. Este comando surte efecto luego de reiniciar el equipo:

PowerShell (Admin) · Activar Enforcement (Valor 1)
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy" -Name "VerifiedAndReputablePolicyState" -Value 1
3

Para desactivar o regresar a modo Evaluación

Si necesitas apagarlo temporalmente o volver a ponerlo en modo de prueba silenciosa:

PowerShell (Admin) · Desactivar (Valor 0) o Evaluación (Valor 2)
# Para apagarlo completamente: Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy" -Name "VerifiedAndReputablePolicyState" -Value 0 # Para dejarlo en Modo Evaluación: Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy" -Name "VerifiedAndReputablePolicyState" -Value 2
4

Reiniciar el sistema para aplicar la directiva CI

El subsistema de Integridad de Código recarga las directivas al inicio del kernel:

PowerShell (Admin) · Reinicio del Sistema
Restart-Computer
¡Listo! Fin del tutorial de Smart App Control Al reiniciar tu equipo, el valor configurado en el registro se aplicará de inmediato. No necesitas hacer nada más para controlar Smart App Control.
TEMA INDEPENDIENTE · AUDITORÍA DE SEGURIDAD

Módulo Adicional: Sysmon Nativo en el Núcleo de Windows 11

A diferencia del tutorial anterior, este apartado no es para bloquear apps, sino para auditar eventos del sistema. Windows 11 26H2 integra por primera vez Sysmon de forma nativa como característica opcional del sistema.

¿En qué se diferencian y por qué son dos temas completamente distintos?
🛡️ Smart App Control (SAC)

Objetivo: Bloqueo y protección. Impide que se ejecuten programas desconocidos, scripts sin firma o malware basándose en IA en la nube.

📊 Sysmon (System Monitor)

Objetivo: Auditoría y telemetría. Registra en el Visor de Eventos todo lo que pasa (conexiones de red, creación de procesos). No bloquea nada.

💡 Activar Sysmon es 100% opcional y no afecta en lo absoluto el funcionamiento de Smart App Control.

A

Verificar si la característica opcional de Sysmon está disponible

Comprueba si tu compilación de Windows 11 26H2 ya tiene el paquete de Sysmon integrado en la imagen:

PowerShell (Admin) · Buscar Característica Sysmon
Get-WindowsOptionalFeature -Online -FeatureName *Sysmon*
B

Activar Sysmon nativo en Windows 11 26H2

Habilita el driver y servicio de telemetría de Sysmon directamente sin necesidad de reiniciar:

PowerShell (Admin) · Habilitar Característica Opcional
Enable-WindowsOptionalFeature -Online -FeatureName "Sysmon" -All -NoRestart
C

Dónde consultar la telemetría generada por Sysmon

Abre el Visor de Eventos con Win + R ejecutando eventvwr.msc y dirígete a:

Ruta en el Visor de Eventos:

Registros de aplicaciones y servicios → Microsoft → Windows → Sysmon → Operational

Preguntas Frecuentes Técnicas

¿Tienen alguna relación técnica Smart App Control y Sysmon?

No, son herramientas totalmente independientes. Smart App Control es una capa de prevención que bloquea la ejecución de ejecutables no confiables o desconocidos. Sysmon es una herramienta de auditoría y registro forense que guarda registros minuciosos de procesos y red para investigaciones de seguridad. Se presentan en la misma página únicamente porque ambas son las dos grandes innovaciones de seguridad de bajo nivel que Microsoft estrena en Windows 11 26H2.

¿Por qué antes era obligatorio formatear para reactivar Smart App Control?

Microsoft diseñó SAC en Windows 11 para que no existiera ninguna ventana de infección previa. Si el usuario instalaba software no seguro con SAC apagado y luego lo encendía, el sistema ya podía estar comprometido. En 26H2, gracias a las mejoras de integridad del kernel y aislamiento por hardware (VBS), la directiva puede reactivarse sin requerir una reinstalación limpia.

¿Qué diferencia hay entre Smart App Control y Microsoft Defender SmartScreen?

SmartScreen solo advierte al usuario al descargar archivos o navegar en Edge. En cambio, Smart App Control opera a nivel del subsistema de Integridad de Código (CI): bloquea por completo la ejecución de cualquier binario sin firma o clasificado como malicioso/desconocido por el modelo de IA en la nube de Microsoft, sin dar opción a saltar la advertencia.
