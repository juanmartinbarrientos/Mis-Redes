Metodología

Cómo lo Hicimos Paso a Paso

La arquitectura exacta para modificar la app oficial de YouTube Music sin romper nada y con carga instantánea.

1

Descubrimiento: Identificar la PWA en Windows

PowerShell

Al pedirle a Antigravity encontrar dónde se guardaba la app, descubrió que YouTube Music no es un archivo `.exe` aislado compilado, sino una PWA (Progressive Web App) administrada por Google Chrome en:

C:\Program Files\Google\Chrome\Application\chrome_proxy.exe --profile-directory=Default --app-id=cinhimbnkkaeohfgghhklpknlkffjgod

Esto significa que la app comparte el motor de extensiones y renderizado de Chrome, permitiendo inyectar CSS y scripts con privilegios completos.

2

Estructura de la Extensión Manifest V3

manifest.json

Diseñamos una extensión ligera sin dependencias externas usando content_scripts. La extensión apunta a https://music.youtube.com/* y se inyecta automáticamente al abrir la app de escritorio o la pestaña web.

manifest.json
Metadatos V3 y reglas
cyber-motion.css
Animaciones y estilos
content.js
Ecualizador y detector play
3

Detección de Reproducción en Vivo (JavaScript)

MutationObserver

Para que el vinilo gire solo cuando suena música y se detenga al pausar, creamos un observador en content.js que escucha el estado del tag <video> y el botón #play-pause-button. Al detectar reproducción, asigna el atributo:

document.body.setAttribute('data-playback', 'playing'); // o 'paused'
4

Instalación en 10 Segundos en Chrome

Modo Desarrollador
  1. Abre Google Chrome y escribe en la barra de URL: chrome://extensions
  2. Enciende el interruptor "Modo de desarrollador" (arriba a la derecha).
  3. Haz clic en "Cargar descomprimida" (Load unpacked).
  4. Selecciona la carpeta del tema que desees (ej: theme music/extension-cyber-motion).
  5. Abre tu app o ventana de YouTube Music y recarga con Ctrl + R. ¡Listo!

Configuración Manifest V3 para Google Chrome 
{
  "manifest_version": 3,
  "name": "YouTube Music - Cyber-Neon Kinetic",
  "version": "1.0",
  "description": "Tema dinámico y animado con fondos Aurora en movimiento, ecualizador visual, vinilo giratorio y efectos láser.",
  "content_scripts": [
    {
      "matches": [
        "https://music.youtube.com/*"
      ],
      "css": [
        "cyber-motion.css"
      ],
      "js": [
        "content.js"
      ],
      "run_at": "document_end"
    }
  ]
}

Detector de reproducción y generador del ecualizador visual 
(function() {
  'use strict';

  // Inyectar fuente moderna Outfit y Space Grotesk
  const fontLink = document.createElement('link');
  fontLink.rel = 'stylesheet';
  fontLink.href = 'https://fonts.googleapis.com/css2?family=Outfit:wght@400;600;800&display=swap';
  document.head.appendChild(fontLink);

  // Inyectar fondo Aurora
  function injectAuroraBackground() {
    if (document.getElementById('cyber-aurora-bg')) return;
    const aurora = document.createElement('div');
    aurora.id = 'cyber-aurora-bg';
    aurora.innerHTML = `
      

      

      

      

    `;
    document.body.prepend(aurora);
  }

  // Detección de reproducción
  function monitorPlaybackState() {
    const video = document.querySelector('video');
    const update = () => {
      const isPlaying = video && !video.paused && !video.ended;
      document.body.setAttribute('data-playback', isPlaying ? 'playing' : 'paused');
    };
    if (video) {
      video.addEventListener('play', update);
      video.addEventListener('pause', update);
    }
  }

  window.addEventListener('DOMContentLoaded', () => {
    injectAuroraBackground();
    monitorPlaybackState();
  });
})();
